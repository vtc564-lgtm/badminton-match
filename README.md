# 배드민턴 게임 매칭

배드민턴 동호회에서 선수를 등록하고, 실력 점수 기반으로 4인 더블 경기를 자동 매칭하는 웹 앱입니다.

## 기능

- **선수 등록**: 이름, 성별, 나이대(5세 단위), 급수, 오늘 출전 여부
- **실력 점수**: 나이·성별·급수를 반영한 점수 산정
- **게임 매칭**: 코트 수에 맞춰 4인 1조, 2:2 팀 밸런스 자동 배치
- **휴식 우선**: 이전 라운드에 쉰 선수를 다음 매칭에서 우선 배치
- **데이터 저장**: 브라우저 localStorage 자동 저장 (PC/모바일 각각)
- **기기 간 동기화**: JSON 내보내기/가져오기

## 실력 점수 기준

| 구분 | 점수 |
| --- | --- |
| S조 | 110 |
| A조 | 100 |
| B조 | 85 |
| C조 | 70 |
| D조 | 55 |
| 초심 | 40 |

- **나이 보정**: 40대 -5, 45세 -8, 50대 -15, 60대+ -25
- **성별 보정**: 여성 -20

## 로컬 실행

```bash
npm install
npm run dev
```

## GitHub Pages 배포

1. GitHub에 `badminton-matcher` 이름으로 저장소 생성
2. 코드 push
3. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정
4. `main` 또는 `master` 브랜치에 push하면 자동 배포

배포 URL: `https://<username>.github.io/badminton-matcher/`

저장소 이름이 다르면 `vite.config.ts`의 `base` 경로를 저장소 이름에 맞게 수정하세요.

## 사용 방법

1. **선수 등록** 탭에서 참가자를 등록하고 오늘 출전을 체크
2. **게임 매칭** 탭에서 코트 수 입력 후 매칭 시작
3. 코트별 A/B팀과 휴식 인원 확인
4. 다른 기기에서 쓸 때는 JSON 내보내기/가져오기 사용
